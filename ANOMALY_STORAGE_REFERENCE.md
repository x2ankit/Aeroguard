## 🔍 How to Extract Anomalies (Code Examples)

### **Method 1: Direct Access**
```python
# After running ad_pipeline.fit()

labels = learner.pipeline['dbscan'].labels_
anomaly_mask = labels == -1
anomaly_indices = np.where(anomaly_mask)[0]

# Get flight IDs
flight_ids = list(binder.bindings.keys())
anomalous_flights = [flight_ids[i] for i in anomaly_indices]

print(f"Found {len(anomalous_flights)} anomalies:")
for flight_id in anomalous_flights:
    print(f"  - {flight_id}")
```

### **Method 2: Using Report Functions**
```python
from flight_ad.report import clustering_info, silhouette

# Get summary statistics
labels, n_clusters, n_noise = clustering_info(learner.pipeline['dbscan'])
print(f"Anomalies: {n_noise}")

# Get quality scores
avg_sil, sample_sil = silhouette(learner.partial_data['pca'], labels)
print(f"Average silhouette: {avg_sil:.4f}")
```

### **Method 3: Create DataFrame**
```python
import pandas as pd

# Create comprehensive report
report = pd.DataFrame({
    'flight_id': list(binder.bindings.keys()),
    'cluster_label': learner.pipeline['dbscan'].labels_,
    'is_anomaly': learner.pipeline['dbscan'].labels_ == -1,
    'silhouette_score': sample_sil
})

# Filter to just anomalies
anomalies = report[report['is_anomaly']]

# Save to CSV
anomalies.to_csv('my_anomalies.csv', index=False)
```

### **Method 4: Get Specific Flight Data**
```python
# Get the actual flight data for an anomalous flight
anomaly_index = np.where(labels == -1)[0][0]  # First anomaly
flight_id = list(binder.bindings.keys())[anomaly_index]

# Load the full flight data
flight_data = binder.retrieve_data(flight_id)
print(f"Anomalous flight {flight_id}:")
print(f"  Duration: {flight_data['time'].max():.0f} seconds")
print(f"  Altitude range: {flight_data['ALT'].min():.0f} - {flight_data['ALT'].max():.0f} feet")
```
